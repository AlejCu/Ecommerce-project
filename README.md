## Ecommerce page
Developed using react, typescript, react router and styled components

https://alejcu.github.io/Ecommerce-project/#/

## What I learned
This project allowed to understand better how to use states in react to keep track of changes in the UI and for it to display acurrate information to the user's needs. I also got more of a hold on how to use reducers to keep track of changes on the cart, since this is being modified from different components within the react project, and this was causing me some issues, so I ended up deciding to add a reducer to the index and this helped me control the changes on the cart easily without adding unnecesary code to each component.

I ended up creating all of my own assets for the site to be able to have full ownership of the whole thing and. I also ended up simulating calling an API by adding a file that included all of the products that would be sold on the store, which ended up being a way better option than just having static items, that would not have allowed me to add some of the features I wanted to add to the site.
