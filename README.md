## Ecommerce page
Developed using HTML, CSS with SASS and Javascript

This website was created to simulate an ecommerce site, you can add items to your cart by clicking on the add button, this will take the value from the name of the item added, the image and the price to be added to the cart.

<img width="1852" height="952" alt="image" src="https://github.com/user-attachments/assets/9c3331ac-fcd5-40bd-afa9-e01cc79d0a2b" />

After clicking on the add button, the cart icon will display a count of how many items you currently have on the cart, if you click on that icon, you will toggle the cart menu, showing you the list of items you have added along with their total.

<img width="1852" height="959" alt="image" src="https://github.com/user-attachments/assets/1478dc4d-1a8c-4a94-a6bf-1f4325a3b7b4" />

Items can also be removed from the cart by clicking on the "x" button.

<img width="356" height="949" alt="image" src="https://github.com/user-attachments/assets/b2031c00-d0e0-458e-9035-9e715f66714e" />

There is also another side menu that can be toggled on the left side, if you click on the hamburguer icon, you will be able to display the menu options to travel to different areas in the site.

<img width="1856" height="958" alt="image" src="https://github.com/user-attachments/assets/f3c59127-6100-4a39-9463-c27bc225ef65" />
